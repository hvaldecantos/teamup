## New Scorer change:

The main idea in the scrorer was write but when the mean was used in the implementation was not quite correct.

### How is the change

* the standardization of the data is ok.

* When applying the mean within each groups' attribute might not be quite useful for now. For example:

group 1: {id: "entity1", a: 4}, {id: "entity2", a: 4}
group 2: {id: "entity3", a:4}

It would e considered a fair partition when it is not. It would represent better the power of the attributes if we just consider the sum of a particular attribute in all entities within a group.

* NormalizedMeanScorer should change name to NormalizedScorer and it should change it implementation to not compute the mean of the entities' attributes in a group.
